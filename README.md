# Abartılı Gecikme Mazereti Üretici

Bu proje, insanlık tarihinin en büyük sorunlarından biri olan 'geç kalma' olgusunu çözmek için değil, onu daha da abartmak için tasarlanmıştır.

## Nedir Bu?

Tamamen bilimsel temelli (yalan), kuantum fiziği, görelilik teorisi, bürokrasi yasaları ve kedi psikolojisi kullanılarak üretilmiş, dünyanın en inandırıcı olmayan ama en abartılı gecikme mazeretlerini üreten bir Python scriptidir.

Gerçekten çalışır. Gerçekten işe yaramaz. Mükemmel.

## Kullanım

```bash
python mazeret_ureteci.py
```

Sonra size 3-5 adet abartılı mazeret verir. İş toplantısına, okula, randevuya, hayatınıza geç kalmak için ideal.

## Özellikler

- Kuantum tünelleme mazeretleri
- Relativistik zaman genişlemesi
- Bürokratik evren çökmesi
- Kedi sabotajı teorisi
- Ve daha fazlası...
